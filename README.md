## [LiberAstra 编排台](https://github.com/liberalchang/LiberAstra)

Self-hosted AIGC orchestration. 只编排、不推理：把 ComfyUI、Ollama 和语音接到同一个工作台（Web / CLI / MCP / OpenAI `/v1`）。程序本身不跑模型。MIT。

[![LiberAstra](https://repository-images.githubusercontent.com/1416382437/34b4a18c-274b-4e41-938d-9272e10d4cfb)](https://github.com/liberalchang/LiberAstra)

```bash
docker compose up -d --build
```

浏览器打开 `http://localhost:8000`。Windows 安装包在 [Releases](https://github.com/liberalchang/LiberAstra/releases)。

公开网页上的 [liberastra.com.br](https://liberastra.com.br/) 是另一个项目。本仓库地址是 [github.com/liberalchang/LiberAstra](https://github.com/liberalchang/LiberAstra)。
